# Bank Deposit Classifier - Proyecto MLOps

Proyecto end-to-end: MLflow + Docker + Kubernetes + Drift.

## Dataset
- Fuente: data/raw/bank-full.csv (UCI Bank Marketing).
- Problema: clasificacion binaria (y: yes/no).
- Registros: ~45211.
